# 画布自动执行：入口、预设与复用证据

## 当前能力

序列帧处理、移除背景和旧抽帧/整理节点右键只提供“自动执行”，预设统一在选中节点右栏编辑，移除重复的右键入口与预设弹窗。动作视频读取所连接处理节点的设置，不设置跨节点预设。追溯必要上游，再继续所点击节点的已连接帧处理分支；不创建节点、不改连线。

预设按工程ID＋节点ID保存于浏览器 `action-forge.node-auto-preset.v2:<工程ID>:<节点ID>`，同类型多个节点也独立，刷新保留；仅点击“保存预设”才写入，未保存修改在切换节点或刷新时丢弃，损坏显式报错。旧全局 `action-forge.auto-preset.v1` 不读取、不自动套用，保留旧存储但不删除。预设仍是浏览器本机数据，不在工作流JSON中，不承诺跨浏览器携带。

- 序列帧处理：开始/结束时间、采样率、循环策略；默认抽帧值沿用该节点已有参数，未配置时0秒至末尾/12帧每秒，默认最少帧可靠循环。
- 旧抽帧节点：只显示时间和采样率；旧整理节点：只显示循环策略。
- 移除背景：自动清理开关、背景来源/颜色、容差、平滑；默认边缘自动取色、容差80、平滑。

右栏预设置于上方，序列帧与透明背景的“打开工作台”入口贴底；内容超出高度时可滚动。抠图预设单列显示，标签与输入统一对齐；自动识别边缘时隐藏背景色，指定颜色时显示，关闭自动清理时收起来源、颜色、容差和平滑，但保留其值供再次开启。右键无预设入口，不创建预设弹窗；已有编辑的覆盖确认弹窗仍保留。

自动执行开始时快照每个处理节点的独立预设，执行到该节点时使用其快照，不用所点击节点的预设覆盖整条分支。增加新节点能力时在 `NODE_AUTO_FIELDS` 注册该类型自己的字段，未接通类型不显示虚假预设。

缺视频、未就绪输入、连接缺失或本机帧集丢失时不可执行。已有输出或编辑需确认覆盖。检测正常完成但未找到可靠循环时，全选当前序列所有帧并继续后续处理，进度提示已全选；检测报错或取消仍停止。循环只改变勾选，不删除其他帧。

## 状态与恢复

1. 首次：视频 → PNG抽帧 → 循环勾选 → 确认序列 → 模型去背景 → 背景清理 → 确认透明输出 → 继续已接通分支。
2. 人工精修不是暂停点；输出后可双击进入，修改沿用下游失效规则。
3. 重跑先确认覆盖。取消/失败保留已完成阶段，清理中已写回的像素与修订保存为草稿，但不发布取消/失败阶段；不承诺跨节点事务回滚。
4. 执行时画布不设整页不可交互：仍可缩放、平移、移动位置、选中查看和播放卡片预览，右栏显示当前任务进度并可取消。暂禁增加/删除节点、改连线、换素材、编辑参数/预设、打开帧编辑器和切换工程，防止污染输入；完成/失败/取消后解除限制。动作片段、组装、预览、导出等未接通节点不执行并明确提示边界；不是完整通用增量调度器。

源帧、模型基底、当前精修结果独立。清理使用源图的边缘连通背景，仅降低当前透明度，不改RGB或覆盖源图/基底。复用旧魔法棒及颜色距离算法，并非第二套模型。每帧最多12百万像素、64个边缘连通区域、45秒分析/清理时限；擦空整帧报错。较大容差仍可能影响相近颜色，不替代人工质量检查。

## 源码证据

- `web/workflow-auto-core.js`：预设校验、最短候选与依赖/后继规划。
- `web/workflow-auto.js`：节点右栏预设及条件显示、覆盖确认、进度取消、既有循环Worker及勾选历史。
- `web/workflow.js`：复用抽帧、整理确认、抠图任务、精修写回及输出。
- `web/workflow-auto-cleanup-worker.js`：边缘取色、背景连通清理及整帧保护。
- 配套 `game-art-matting/web/src/editor.js` 的 `connectedMask` 与 `web/src/color-distance.js` 的 `seedColorDistance`：既有魔法棒核心，通过 `scripts/build-auto-cleanup.mjs` 隔离打包为 `web/workflow-cleanup-core.js`，内含Culori MIT许可。

重建需配套项目源码及npm依赖，执行 `node scripts/build-auto-cleanup.mjs`；路径沿用 `FRAMES_MATTING_ROOT`。已构建产物随本仓库提供，不改独立8896。模型依赖见[仓库边界](../repository-guide.md)。无新增后端接口，这次静态改动不需重启8897。
