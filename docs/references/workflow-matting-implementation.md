# 透明背景节点：旧链路功能核对

当前实现：R6-C6。入口仍为原浏览器 `127.0.0.1:8897/workflow`，不切换浏览器或站点数据源。

| 旧版能力及源码 | 新版落点 | 不变式 |
| --- | --- | --- |
| `web/matting-ui.js` 批量/补抠/重抠/取消/失败定位 | `workflow-matting.js`、透明背景工作台 | 完整任务才发布；失败保留原有草稿，迟到结果不绑定新输入 |
| `app/batch_matting.py`、`app/batch_model_worker.py` | 独立 `/api/workflow-matting/jobs` 适配器 | 复用同一模型与局部FFmpeg去绿，不复制算法，不调用旧页会话 |
| 原图/自动/当前/缩略图与精修修订 | 浏览器帧集草稿及后端临时恢复 | 三份像素独立；补抠按帧身份和原始内容哈希复用精修 |
| `web/matting/repair.html` 移动、擦除/恢复画笔、魔棒、容差、边缘平滑、选区去除/恢复、撤销/恢复/重置、缩放、检查背景 | 原精修编辑器嵌入，通过构建适配显式API前缀 | 私有源码不复制整仓、不修改核心；关闭必须等待精修flush及本机保存 |
| 逐帧/循环播放、双击精修 | 共用播放器及单行时间轴 | 播放参数不改变输出时长，缩略图按可见范围解码 |
| 旧页“加入角色项目”和导出 | 透明帧集输出端口 | 新版下游动作/导出节点尚未接通，不伪造项目迁入或下载能力；旧 `/projects` 仍独立可用 |

布局沿用顶部全局导航、内侧限宽主预览、272px右侧操作、220px贴底时间轴。不再提供原始帧/透明结果页签；未处理时直接查看原始帧，当前帧已有自动结果后自动提供左右滑动对比，原图和当前精修结果共用尺寸、缩放与位移。检查背景以色块放在预览区右下角，仅影响显示、不改PNG；底部缩放在左、播放居中，窄屏分两行；顶部不重复展示已处理数量；未处理帧不显示对比线。双击预览画面或时间轴帧进入精修，不再提供右栏精修按钮。精修嵌入层通过 `web/matting/embed.css` 统一深灰与冰蓝，不修改私有单图应用主题或处理核心。

存储边界：浏览器 IndexedDB 是已完成透明帧及精修结果真值；后端缓存可从这些PNG显式恢复以继续精修，不是磁盘工程备份。只支持既有固定处理管线，不展示未实现的去绿强度。

工作台顶部名称在左，状态和“返回画布”在右；返回保留画布视野、节点和选择。1920、1280、800像素宽度下验证按钮完整可见且不与状态重叠。

精修弹窗使用右上角X关闭，不另设“完成精修”文字按钮；关闭仍等待flush确认与本机保存，失败留窗重试。主工作台确认输出仅在全部帧已处理且无运行任务时显示；未处理、处理进行中或取消后的不完整结果不能确认输出。

## 验证与限制

- 2026-10-11 真实输入回归：抽帧协议只有稳定帧ID和视频解码帧 `sourceFrameIndex`，不含整理器内部 `sourceIndex`。透明背景的显示编号及请求映射统一读取帧ID采样尾号，不将视频帧序号或重排后的位置冒充原始采样编号；测试必须覆盖真实抽帧、勾选部分帧后接去背景。没有透明结果时直接显示原始帧且不显示对比线，未处理帧不以原图冒充透明结果。
- `tests/test_workflow_matting.py`：真实RGBA、源图不变、精修修订冲突、跨服务重启恢复不调用模型、补抠只调用新帧且保留手工像素、错误上传/取消/模型失败不发布。
- 显式CPU真实模型：1280×720角色源PNG通过新接口处理；透明通道范围0–255，763719像素全透明，142147像素全不透明。验收副本在本机忽略目录 `output/acceptance/workflow-matting-real.png`。不能用合成浏览器处理器代替此证据。
- `tests/browser/workflow-matting.spec.js`：确定性像素、播放、精修保存/关闭/刷新、服务任务显式恢复、回读失败留窗重试、重新处理取消、确认后下游整理、600帧按需缩略图与取消。1920×900、1280×600、800×900截图与几何断言；网格仅在图片内，操作栏和时间轴贴底。
- 每任务最多600帧、12M像素/帧；上传源图及恢复像素合计最多256 MiB，下载结果合计最多256 MiB。单模型任务最长45分钟，上传租约15分钟。长序列布局验证不代表600帧真实模型吞吐验收。
- 原始/自动/精修必须是同尺寸PNG；签名包含上游资产及确认签名、节点参数和管线版本，补抠仅按帧ID及源内容哈希复用。改名、移动与预览速度不改变像素结果；重新处理全部帧必须确认。
- 仅接通透明帧输出及下游序列帧处理；动作片段、角色组装、引擎预览和导出还未接到画布，不以旧页能力冒充新版完成。
