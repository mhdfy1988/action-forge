## 使用流程

导入动作视频 → 连接提取序列帧 → 打开抽帧工作台 → 设置开始/结束/采样帧率 → 提取 → 检查并返回画布。

输入必须是已确认的视频资产。输出为`frame-set/source`，包括原尺寸PNG、逐帧时长、实际来源PTS和采样时间；不做低分辨率缩略图转存，不改变原视频。默认全片12帧/秒；单次最多60秒、600帧，本机帧集保存预算256 MiB。

## 状态与结果

- 未连接或未导入：等待视频；输入可用：等待提取。
- 执行：真实上传/处理/保存进度，单页同时一个抽帧任务，可取消。
- 已就绪：PNG写入IndexedDB完成且清单保存成功后才发布结果。
- 改参数、换输入或连接变化：旧结果待更新，仍可查看，不当作当前结果交付。
- 输入签名相同且已有确认结果：复用；改名和移动不触发重算。
- 取消、删除、清空或运行中输入变化：迟到结果不得覆盖当前图；失败保留旧结果。

浏览器保存帧集，服务器只保存有预算的临时任务。刷新或重启服务器不依赖旧任务读取PNG；清理站点数据会丢失素材，目前无磁盘工作流工程备份。复制工作流共享不可变素材引用，删除工作流不清理其他画布素材。运行中刷新不恢复未完成任务，后端仍有任务时间上限。
