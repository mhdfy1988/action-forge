# 动作循环检测试验版

日期：2026-10-06。用户认可技术方向并授权“先试试看”。仅M2循环辅助检测，不启动重复/跳变检测、M3抠图或M4动画编排。主入口8897，8896不干预。

## 操作与状态

整理帧 → 寻找循环 → 候选弹窗 → 单帧/循环播放检查 → 只保留这个循环。

- 分析全部当前保留帧，按当前顺序；不以勾选集合为输入。
- 点击候选只改变弹窗预览，不改变主序列、勾选、查看或历史；主预览播放先暂停。
- 弹窗左侧最多5个候选，显示实际包含帧数、起止原编号、当前位置。排序后原编号不连续甚至逆序是合法的，不能用原编号相减来计算帧数。
- 右侧使用原尺寸PNG预览；默认12、1–60帧/秒，连续循环、暂停、前后逐帧。调速沿现有进度继续，只影响本弹窗；不展示视频来源时间、不写入导出loop或时长。
- 点击“只保留这个循环”才以FrameEditor.commit裁去区间外帧，一步历史；勾选过滤保留，若当前查看被移除则看第一保留帧。撤销还原裁剪前的顺序、勾选和查看，恢复重新执行裁剪。
- 取消/关闭/Escape终止分析与播放，结果不能迟到后复活。没有可靠候选显示空结果；读取、线程、超时失败显式显示，不静默换算法。
- 输入快照包含revision和完整有序ID。确认时同时检查版本和顺序；删除、交换、撤销之后即便回到相同顺序，旧候选仍失效。

状态：空闲 → 分析 → 候选 / 无候选 / 失败；关闭回空闲，确认才提交编辑。正常M2勾选帧播放仍是单次播放，未被弹窗的循环模式覆盖。

## 实现与复用

- `web/loop-core.js`：图像特征、重复邻域/接缝、候选去重与绑定、版本检查；不访问DOM/网络，不改图像。
- `web/loop-worker.js`：单工作线程，复用本机源帧缩略图接口；OffscreenCanvas解码特征，顺序处理并关闭ImageBitmap。
- `web/loop-ui.js`：原生dialog、异步原PNG预览、取消/超时/版本边界；通过适配入口提交既有编辑核心。
- `web/organizer-ui.js`仅接入口与锁定/快捷键边界；复用FramePlayback.position取余实现循环，不复制/修改主播放时钟。
- HTTP、PNG解码、线程、弹窗复用浏览器/现有服务；无新增Python/Node依赖、CDN、模型或GPU。核心动作筛选为项目领域启发式，自己保留可测试边界，非手写通用HTTP/图像解析协议。

## 分析规则与资源

1. 把缩略图整幅画布统一映射到24×24特征；不逐帧裁切、居中或自动稳定角色。所有帧使用同一映射，角色位移不能被归一化掩盖。
2. 首帧边框至少80%明显绿像素才估计亮绿底色；接近该颜色的区域降低比较权重。每格保留RGB、粗前景权重和横向颜色梯度；距离按两帧前景并集归一化，避免大绿幕抬高相似判断。这不是抠图，不应用到任何输出PNG。绿色衣物近似底色仍可能影响检测，不能承诺语义识别。
3. 构建对称帧距离矩阵，再找重复相位。比较两处前后最多5帧、至少3对对应画面，检查相邻变化向量的方向一致性；第一版未引入光流或姿态模型。
4. 假设start和repeat是同一阶段，保留[start,repeat)，实际接缝是repeat-1→start。重复端点不重复包含；再检查接缝大小及相邻变化向量，而不是只看start与repeat。
5. 排除静止/变化过小、方向不一致和接缝突变。内部匹配评分只用于排序，不是概率；质量分档相近时优先较短完整周期。相近周期且区间重叠超过一半去重，保留不同片段/周期供用户看。

当前固定启发式由自制开发夹具检查，未经过真实游戏素材质量标定。代码中的阈值不得写成“95%平滑度”或通用99相似度；改变阈值后必须重跑误报、漏报和导出保护测试。

- 输入7–600帧，候选至少4帧，最多5条。
- 分析全程45秒上限，单次帧读取10秒上限；超时/取消terminate线程，不让计算挤在主交互线程。
- 单工作线程、一个24×24离屏画布、逐图解码即释放；600帧特征约6.6MiB，距离矩阵约1.4MiB，不加载600张原图RGBA做全对比较。
- 弹窗仅预览原PNG；工作线程的缩略图和分析特征不得成为导出图片。导出仍调用既有v3接口，包含全部保留帧的原字节。

## 限制与下一步

- 试验版是“推荐区间”，不是识别动作名称，也不是自动修复接缝。一次性动作、AI角色变形/漂移、过稀采样或只有一个周期且没有重复相位上下文，可能无候选或误报；需实际预览确认。
- 24×24特征可能漏掉细小手指/饰物变化；尚无高分辨率接缝二次检查或光流验证，不能以自制夹具通过宣称商业级效果。
- 先收真实跑步/待机素材试用反馈，记录误选半周期、漏检、接缝突变及耗时，不用私人素材反复调阈值后再称独立测试。
- 后续仅在证据需要时，对少量候选加入更高分辨率/光流验证；重复/跳变检测、自动混帧/补帧、M3/M4均不在本轮范围。
