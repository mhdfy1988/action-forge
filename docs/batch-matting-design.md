# 当前批量抠图与精修

帧处理页中整理和抠图自由切换，无“结束整理”。抠图接当前全部保留的有序帧，不借用勾选集合。按稳定ID关联结果；删除/交换/撤销不丢人工修改，恢复未抠帧时补抠缺失帧，已有修订不重算覆盖。

## 模型与依赖

策略model-local-despill-v1：独立Python进程调用配套GameArtEngine.cutout(postprocess=False)，沿已验证路由生成模型Alpha，再对可靠亮绿幕轮廓窄边应用局部FFmpeg去溢色。Alpha和主体内侧核心保持；其他背景明确记录跳过理由，FFmpeg错误显式失败，不静默回旧算法。

model_config.py统一Python模型目录/解释器；构建脚本采用同一个FRAMES_MATTING_ROOT配置名。默认同级game-art-matting，模型环境默认该项目.venv/Scripts/python.exe。FRAMES_MODEL_PYTHON可指定其他已安装配套环境；仅配置不加载模型。独立进程取消只结束本批拥有的进程树，CPU测试可指定FRAMES_MATTING_CPU_ONLY=1。

公开仓库不包含私有模型核心或权重；缺少配套依赖时完整链路不可用，详见[安装边界](repository-guide.md)。不把合成测试处理器当生产模型。

## 精修与结果

双击帧卡片/大图打开双侧精修弹窗；画笔和魔法棒可在两侧操作，每笔、撤销/恢复、重置自动同步。关闭须收到本次flush确认，失败保留脏修改并允许重试。源图、自动结果不可变，人工结果另存修订。嵌入资源随本项目提供，不改变独立8896的静态资源。

透明播放覆盖当前全部保留且已抠帧，默认12、1–60帧/秒，不改变源或输出设置。未抠帧须补抠才可进入统一导出。服务重启/刷新不恢复浏览器编辑工程，需要先下载所需结果。

## 验证

tests/test_batch_matting.py及浏览器用例验证资源、修订、失败/取消/历史和关闭同步；真实模型测试为显式开启的独立门槛，不能由合成用例通过推断模型质量。[早期完整设计](history/batch-matting-design.md)保留历史，不作为当前入口说明。
